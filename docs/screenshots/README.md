# Application Screenshots & Visual Assets Directory

This directory is designated for high-resolution interface captures, visual analytics charts, and deployment diagrams demonstrating the platform in operation.

## Recommended Screenshots Layout

```
docs/screenshots/
├── dashboard.png      # Primary React Dashboard overview with live telemetry cards
├── live_stream.png    # Live WebSocket streaming view with bounding boxes and track IDs
├── image_detect.png   # High-resolution image detection interface with confidence sliders
├── video_tracking.png # Video file tracking playback with persistent trajectory rendering
├── analytics.png      # Spatial analytics view displaying virtual line tripwires & class breakdown
└── model_manager.png  # Dynamic Model Registry management and runtime switching view
```

> **Note on Visual Artifacts:** In accordance with repository integrity standards, visual captures must depict genuine executions of the application against actual media samples (`data/samples/bus.jpg`, `sample_real_bus.mp4`) without mock or synthetic graphics.
